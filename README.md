# Hair studio plan

Decision dashboard for a non-surgical hair replacement (hair patch) studio in New Gurgaon, Sep 2026.

Next.js 16 · App Router · Tailwind v4 · shadcn/ui (sidebar layout) · Recharts.

```bash
npm install
npm run dev
```

All numbers live in `src/data/insights.ts` — edit there, every page reads from it.

Pages: Overview · Revenue model · Where to open · Competitors · Unit economics · Sourcing · Compliance · Launch plan · Risks · Manufacturing later.

Sources: Google Places (13 Sep 2026), IndiaMART / Made-in-China listings, Delhi/Bangalore clinic price guides, own model. Figures are estimates — validate with the ads test and mystery-shopping before committing capital.
